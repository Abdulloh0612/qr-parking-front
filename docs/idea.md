Проект: Qr-Code информация

Описание: Есть наклейки Qr код которые крепятся к машине. Логика в том что при первом сканировании должно быть регистрация машины и контактных данных. При следующих сканированиях должно открывать страницу с этими контактными данными. Это нужно для того чтобы если машина неудобно припорковалась или что то типо того то можно было связаться с владельцом машины.

Требования:

- красивый UI как в яндексе
- Анимации ( минимальные чтобы потянул любой телефон )
- Очень хороший UX, приложение делается под Кыргызистан надо под них сделать удобно
- Использовать React + Tailwind. Хорошая файловая структура ( для маленького проекта )

Стиль:

- минимализм
- стеклянные эффекты / blur
- плавные hover
- аккуратная типографика

Логика:

- Страница регистрации:
    - Первый этап - ввод обязательных данных, "телефон номера, имя, фамилия, номер машины, марка машины".
    - Второй этап - ввод соц сетей. " WhatsUp, Instagram "
    - Дополнительный этап - опционально выбрать фотку, включить или выключить отзывы. На выбор можно зарегестрировать свой телеграмм аккаунт к боту который может отправлять сообщения от " пострадавших ".
- Страница аккаунта:
    - После регистрации аккаунт должен быть открыть типо у пользователя и там всего одна страница где данные, сколько раз сканировали, все сообщения которые были отправлены боту в телеграмме, и отзывы. Аккаунт должен открываться по device_id без токен системы
- Страница после сканирвоания QR ( чтобы связаться ):
    - Должно отображаться: Контактные данные, средний рейтинг, и через сайт отправка сообщения в телеграмм. Интервал 1 минута перед каждым сообщением
    - Человек не будет регистрироваться, просто данные и все. Остальное на клиенте.
    - Возможность оставить рейтинг
- Везде должны быть контактные данные для помощи. Одни контактные данные

Api модель - бэкенд еще не готов так что ты должен подключить к бэкенду но не к реальному просто сделай список всех апишек и как они должны работать ( как в сваггере ) и используй функции которые подключены к не готовым апишкам чтобы потом не пришлось менять. Создай файл типа сваггера где описаны все апишки. Единственное что я сделаю это просто добавлю в .env url к серверу и он должен сам срабоать. А если не подключу то все равно должен работать как в статике. Но сразу напиши легкий код чтобы я без проблем удалил статику чтобы не было лишнего

Правила даже нету условия для работы то ошибки должны быть красивые.
