# QR Contact - Кыргызстан

Приложение для связи с владельцами автомобилей через QR-коды.

## 🚀 Технологии

- **React 18** + **TypeScript**
- **Vite** - быстрая сборка
- **Tailwind CSS** - стилизация
- **Framer Motion** - анимации
- **React Router** - роутинг

## 📱 Основные страницы

- `/` - Главная (редирект на аккаунт или регистрацию)
- `/qr/:id` - **Редирект страница (точка входа при сканировании)**
  - Проверяет статус QR кода
  - Первое сканирование → `/register?qr={id}`
  - Повторное → `/contact/{id}`
- `/register?qr={id}` - Регистрация QR кода (3 шага)
- `/account` - Личный кабинет (по device_id)
- `/contact/{id}` - Страница контакта владельца

## 🔄 Логика работы

### Сценарий 1: Первое сканирование QR кода
1. Пользователь сканирует QR → `/qr/ABC123`
2. Система проверяет: `GET /api/v1/qr/ABC123/status` → `{ registered: false }`
3. Редирект на `/register?qr=ABC123`
4. Пользователь заполняет форму регистрации (3 шага)
5. После регистрации → редирект в `/account`

### Сценарий 2: Повторное сканирование
1. Другой пользователь сканирует тот же QR → `/qr/ABC123`
2. Система проверяет: `GET /api/v1/qr/ABC123/status` → `{ registered: true }`
3. Редирект на `/contact/ABC123`
4. Отображаются контакты владельца, можно отправить сообщение

### Сценарий 3: Владелец заходит в аккаунт
1. Владелец открывает приложение → `/`
2. Система проверяет device_id в localStorage
3. Если есть → редирект в `/account`
4. Если нет → редирект на `/register`

## 📡 API интеграция

Приложение работает в двух режимах:

1. **Mock режим** (по умолчанию) - без реального backend
   - Данные хранятся в localStorage
   - Для тестирования UI/UX
2. **Production режим** - при указании `VITE_API_URL`
   - Все запросы идут на реальный API
   - Полная функциональность

Переключение происходит автоматически. Mock данные можно легко удалить из `src/lib/api/mock.ts` после подключения реального API.

## 📖 API документация

См. `docs/api-spec.md` для полной спецификации API.

Ключевые эндпоинты:
- `GET /qr/:id/status` - проверка регистрации QR
- `POST /qr/register` - регистрация нового QR
- `GET /qr/:id` - получить контакты владельца
- `POST /qr/:id/message` - отправить сообщение
- `POST /qr/:id/rating` - оставить отзыв
